🧠 IMU Brainstorm — M5StickS3

BMI270 6-axis accelerometer + gyroscope — what can we do with it?

👆 Tap Detection Easy

Double-tap the StickS3 body to toggle the current task. No need to find the tiny button. The accelerometer detects the sudden vibration spike from a tap.
// Simple tap detection: monitor acceleration magnitude M5.Imu.update(); float ax, ay, az; M5.Imu.getAccel(&ax, &ay, &az); float mag = sqrt(ax*ax + ay*ay + az*az); // If magnitude spikes above ~2.5G, count as a tap // Two taps within 500ms = toggle current task
Instant toggleNo button huntingFeels premium

👋 Pick-up Wake Easy

Screen off when sitting on the desk. Pick it up — screen turns on immediately. Uses gyro to detect rotation and accelerometer to detect motion, similar to how smartwatches work.
// Detect pick-up: watch for acceleration change > 0.5G // Combined with gyro rotation change = wake screen // Screen stays on for 10 seconds, then dims again
Battery savingAlways ready

📊 Step Counter Medium

Track daily steps using the accelerometer. Show step count on the progress bar (e.g., steps alongside tasks). Wrist/desk-worn pedometer.
// Step detection: look for peak in acceleration during walking gait // Typical step: 0.5-2.0G spike at ~1-2 Hz // Count steps, store in RTC-backed memory, reset daily
Health trackingUnique feature

📱 Orientation Switch Easy

Hold the StickS3 vertically for task list, rotate horizontally for a different view (e.g., stats or weekly summary). Auto-flip the screen based on orientation.
M5.Imu.update(); // If Z-axis gravity > 0.7G → device is flat on desk → show task list // If X-axis gravity > 0.7G → device is rotated → show stats view
Two viewsNo extra button

🥤 Shake to Clear Medium

Shake the device to delete all completed tasks at once. Aggressive shake (>3G multiple times in 1 second) triggers a cleanup.
// Detect shake: count acceleration peaks > 3G // If 3+ peaks in 1 second = shake detected // Confirm with "Shake to clear done tasks?" on screen
SatisfyingQuick cleanup

🔔 Desk Notification Medium

When a task is overdue or the device has been idle for a while, it can vibrate or tap the desk. The IMU can detect if someone is sitting at the desk (tiny vibrations from typing/footsteps) and only notify when relevant.
Context-awareLess annoying
